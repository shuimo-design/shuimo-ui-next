# 组件缺口与特色构想

日期：2026-09-16
对照对象：Ant Design 5、Element Plus、Arco Design、Naive UI（下文简称"四家"）。
现状：61 个组件（见 `docs/api/`），表单 / 反馈 / 导航的主体位都已占住，另有四家没有的水墨特色件（宣纸、笔触边框、印章、打字机、落墨转场）。
本文件是规划清单，不是承诺；做完一项就删一项。

## 排序的尺子

不用"四家全有就得有"这把尺子——那是给企业后台库的。选这个库的人做的是博客、个人站、文化 / 茶 / 书画类品牌站、作品集、文档站。这类场景里穿梭框、级联选择、树选择、图片墙上传的出场率很低，做了是给别人的赛道补课，而且各自都是硬骨头。

这里按三件事打分：**目标场景里的出场频率 × 水墨风能不能加分 × 现有积木够不够**。"积木"指 `core/src/ink/` 下现成的引擎资产和已有的组件。

## 四、明确不做

理由都是一条：目标场景里没人找它们，或者 CSS 一行就够。

Transfer、Cascader、TreeSelect、Calendar 独立面板、Layout、Segmented、Statistic、Typography、Result、ColorPicker、Mention、QRCode、Tour、FloatButton、Split、Affix（sticky 一行）、Space（gap 一行）、Input.OTP、TextEllipsis（line-clamp 够用）、朴素版 Signature。

## 特色件的设计纪律

落地时同样受 `notes/COMPONENT-CONVENTIONS.md` 约束，三条要提前想清楚：

1. **确定性**：所有随机由 `seed` 驱动，服务端和客户端首帧一致，SSR 冒烟（`check:ssr`）必须过。
2. **动效令牌**：只用 `--m-duration` / `--m-ease`，减弱动效时自动归零；滚动驱动的效果在 Safari 17 上要能静态降级。
3. **字体授权**：竖排诗文、篆数统计的理想形态依赖手写字体，wljh 的商用授权未解决（notes/PLAN.md 有记录），先按"没装就退回黑体"的口径做，授权落定后再升级。
